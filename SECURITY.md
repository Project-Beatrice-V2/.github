# Security policy

Report a suspected vulnerability using **Security → Advisories → Report a vulnerability** in the affected repository. The report is private and goes to the maintainers. If the private report button is unavailable, contact a listed maintainer privately to arrange a disclosure channel.

Include the affected repository and version, platform, steps to reproduce, and the impact you observed. Redact credentials, personal data and sensitive audio. Keep exploit details out of public issues, pull requests and discussions while the report is under review.

We prioritize issues that affect the current release or the default branch. If you found the issue on an earlier release, include that version and whether the behavior persists on the latest version.
